# Polars Processing

Curated Polars learning example migrated from `searchs/polars-processings` during repository consolidation.

The original repository mixed a simple Polars dataframe exercise with unrelated project metadata and dependencies. This copy preserves the useful dataframe work only: date extraction, derived BMI calculation, CSV write/read round-tripping and idiomatic `with_columns` usage.

Run with a recent Python 3.12+ environment containing `polars`.
